Terminal commands · python3 -m relay

RUN FROM PROJECT ROOT
List all available commands

Show CLI help for the Relay version installed in this workspace.

python3 -m relay --help
Start the dashboard

Starts a local dashboard bound to 127.0.0.1 by default.

python3 -m relay dashboard
Create or refresh a handoff

Replace my-task with a short unique ID for your task.

python3 -m relay handoff --task my-task
List saved handoffs

List handoff files tracked in this workspace.

python3 -m relay handoff list
Get handoff advice

Evaluate available task/checkpoint signals and suggest the next step.

python3 -m relay handoff advise --task my-task
Validate recovery readiness

Compare saved recovery data and workspace state; this command does not edit files or start an agent session.

python3 -m relay resume --task my-task
Show workspace and task status

Print saved tasks, active task, Git state and available recovery signals.

python3 -m relay status --task my-task
Write a checkpoint

Capture mechanical workspace state without an LLM; add --write-handoff to also write HANDOFF.md.

python3 -m relay checkpoint --task my-task --write-handoff
Choose the active task

Set the task ID used by commands that rely on the active-task registry.

python3 -m relay task set my-task
Show or clear active task

Use get to inspect the active task, or clear to remove the active-task selection.

python3 -m relay task get
python3 -m relay task clear
Mark a task done

Marks the checkpoint complete and removes its HANDOFF.md; checkpoint/history and project files remain. Requires an existing handoff.

python3 -m relay handoff done my-task
Delete a handoff file

Removes only HANDOFF.md. The --yes flag confirms this action; checkpoint/history and project files remain.

python3 -m relay handoff delete my-task --yes
Validate a checkpoint

Check a checkpoint JSON file against the current schema.

python3 -m relay validate plans/handoffs/my-task/checkpoint.json
Print example configuration

Print a sample relay.toml; redirect to a file only if you intend to create one.

python3 -m relay example-config

Important notes

Slash commands must be pasted into a compatible coding-agent chat where the Relay handoff skill is installed. They are not terminal commands.

Terminal commands must be run from the project root in a terminal where Relay is installed. Replace my-task with your real task ID.

The resume CLI command checks recovery readiness; actual continuation happens when you invoke the agent's /handoff resume command in a supported agent session.

Done and delete are different: done marks a task complete; delete removes only its handoff note.
